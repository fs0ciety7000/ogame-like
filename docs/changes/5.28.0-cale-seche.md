# 5.28.0 : Cale sèche et hangars remis d'aplomb

Type : fonctionnalité + correctif
Statut : livré (PR fs0ciety7000/ogame-like#144)

## Demande
> « Taille Hangar attaque/défense : nombre vaisseaux dépasse la limite depuis maj des reparations. […] Il faut un workflow complet de game design et level design. »

## Diagnostic
- Comptabilité du combat saine, prouvée par simulation (attaque à quai et en vol, défense avec Atelier).
- Cause principale : la migration 5.22 `restoreWorkshopUnits` (`cosmic_db.js`) rendait les vaisseaux sauvés sans plafond.
- Causes annexes :
  - Ascension qui remettait les hangars au niveau 1 ;
  - stat `hangarCapacity` jamais lue ;
  - tech hors colonies ;
  - trois copies du calcul des places.

Le détail C1 à C6 est dans la proposition.

## Ce qui change
- Joueur :
  - Nouveau bâtiment Cale sèche (Atelier niv. 5), avec ses paliers :
    - Triage à 5 ;
    - remise automatique à 10 ;
    - priorités à 15 ;
    - Cale orbitale à 20.
  - Vaisseaux « prêts » à remettre en service.
  - Surcharge du hangar affichée avec ses sorties.
  - Hangars conservés à l'Ascension.
  - Bonus de hangar actifs, tech de hangar appliquée aux colonies.
- Admin : règles « Cale sèche » (remboursement, bonus de cadence), effet de bâtiment `dock`, prérequis `requires`, migration de contenu `cale-seche-5.28`.
- Code :
  - `src/game/hangar.ts` (nouveau) ;
  - `workshop.ts` (allocation des postes, prêts, Triage, priorités) ;
  - `actions.ts` (`dockCommission`, `dockScrap`, `dockSettings`, `actionNeedsAway`, `awayKnown`) ;
  - `buildings.ts`, `ascension.ts`, `colonies.ts` ;
  - `cosmic.pb.js` (lecture des flottes en vol) ;
  - `DockPanel.tsx`.
