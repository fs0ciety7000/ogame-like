## Diagnostic
Aucune identité d'empire : toutes les sources de bonus finissent identiques. Le circuit d'effets accepte une nouvelle source ; les plafonds de
durée (50 %) laissent 9 points de marge, d'où −8 % au plus sur les temps (`derived.test.ts` le vérifie).

## Ce qui change
- Joueur :
  - page **Classe d'empire** (menu Empire) : Industriel, Seigneur de guerre, Explorateur, chacune avec 3 effets et 1 avantage propre ;
  - premier choix gratuit ; changer coûte **100 Ambre**, une fois tous les **7 jours** ;
  - rappel sur l'accueil tant qu'aucune classe n'est choisie ;
  - le compteur d'emplacements de flotte, le compteur de chantiers et la limite d'expéditions tiennent compte de la classe.
- Admin : Règles → Classes d'empire (prix du changement, délai). Rapport d'impact : source « Classe d'empire ».
- Code :
  - `empireClass.ts` (définitions, effets, avantages), `empireClassChoose.ts` (action, séparée pour éviter un cycle d'import) ;
  - `effects.ts` (source `class`), `modifiers.ts` (`empireEffects`), `impact.ts` ;
  - `buildPlan.ts` (`buildSlots`), `fleets.ts` (`fleetSlots`), `expeditions.ts` (`expeditionsPerDay`) ;
  - `actions.ts` (action `empireClass`), `playerFields.ts`, `types/game.ts`, `pb_schema.json` (champ `players.empireClass`, ajouté au
    démarrage par la synchronisation du schéma) ;
  - `content.ts` (règles `classes`), `panels.tsx`, `EmpireClassPage.tsx`, `App.tsx`, `NavBar.tsx`, `DashboardPage.tsx`, `FleetsPanel.tsx`,
    `ExpeditionCard.tsx`, `EffectSheet.tsx`, `ImpactReportPanel.tsx`.
