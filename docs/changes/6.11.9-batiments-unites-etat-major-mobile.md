## Ce qui change
- Pour le joueur, sur téléphone :
  - Bâtiments : le coût de déblocage passe dans une pastille au-dessus d'un bouton « Débloquer » (sur tous les écrans) ; un bâtiment
    verrouillé a une image plus petite, une description sur 2 lignes et plus de niveau « 1 / 20 » ;
  - Unités : la posture de la base devient un sélecteur à trois colonnes avec la seule description de la posture choisie ; les deux
    jauges de capacité côte à côte ; les filtres de classe sur une ligne qui défile ; cartes plus serrées ;
  - État-major : les officiers rares (ils ne se recrutent pas) démarrent repliés.
- Pour l'admin : sans objet.
- Dans le code : `BuildingsPage.tsx`, `UnitsPage.tsx`, `FormationPicker.tsx` (`PosturePicker`, aussi dans le simulateur), `CommandPage.tsx`.
