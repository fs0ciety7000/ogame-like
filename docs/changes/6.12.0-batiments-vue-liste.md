# 6.12.0 : Vue « liste » de Bâtiments sur téléphone

Type : fonctionnalité
Statut : livré (branche `claude/hiver-k-s`, sans PR : Q12)
Proposition : aucune (lot R2 de `docs/proposals/feuille-de-route-2028-ete.md`, Q16 tranchée par l'option recommandée)

## Demande
Q16 : Bâtiments faisait 6 271 px à 375 px pour un joueur avancé (vingt cartes ouvertes).

## Diagnostic
Mesure `pagelen-adv.mjs` (6.11.13) : chaque carte débloquée fait environ 300 px (image, description, production, coût, bouton).

## Ce qui change
- Pour le joueur, sur téléphone : deux puces « Cartes » et « Liste ». En liste, une ligne par bâtiment (vignette, nom, niveau, « Prêt »
  si l'amélioration est payable, compte à rebours si un chantier tourne) ; un toucher ouvre la carte complète, « Replier » la referme.
  Par défaut : liste au-delà de 10 bâtiments débloqués, cartes avant. Le choix est gardé sur l'appareil.
- Pour l'admin : sans objet (affichage seulement).
- Dans le code : `BuildingsPage.tsx` (`readBuildingsView`, `VIEW_KEY`, `LIST_VIEW_MIN_UNLOCKED`).

## Décisions et écarts
- Mesures : joueur avancé **6 271 → 1 814 px** (liste) ; joueur neuf inchangé (4 727 px, cartes).
- Le seuil de 10 est une constante d'affichage, pas une règle de jeu : elle reste dans le code (règle n° 2 : chiffres de jeu seulement).
- Sur ordinateur, rien ne change (bascule masquée au-delà de 640 px).

## Invariants et tests
Sans objet (pas de règle de jeu).
