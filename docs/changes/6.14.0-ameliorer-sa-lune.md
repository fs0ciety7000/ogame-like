# 6.14.0 : Améliorer sa lune

Type : fonctionnalité
Statut : livré (branche `claude/hiver-k-s`, sans PR : Q12)
Proposition : `docs/proposals/lunes.md` §8 (option C1, appliquée seule : Q18) ; lot H28-1

## Demande
AU28-3 : la lune était un bonus passif, sans rien à jouer autour.

## Diagnostic
Rapport d'impact : bouclier empire 3 % sur 15 % (12 points de marge) ; entrepôt à l'abri déjà à 25 % sur 25 %. Seul le bouclier peut monter.

## Ce qui change
- Pour le joueur : Statistiques, carte Planète mère : « Améliorer » à côté de la lune. Niveau 2 à 5, +2 % de bouclier chacun (11 % au
  niveau 5) ; coût 500 k ferraille + 250 k énergie, doublé à chaque niveau ; confirmation avec le coût. L'entrepôt à l'abri reste à +5 %.
- Pour l'admin : Règles → Lunes : niveau maximal, bouclier par niveau, coût du niveau 2 (ferraille, énergie), multiplicateur.
- Dans le code : `moon.ts` (`moonLevel`, `moonShield`, `moonUpgradeCost`, champs de `MOON_RULES`), `moonUpgrade.ts` (`upgradeMoon`),
  `actions.ts` (action `moonUpgrade`), `impact.ts` (maximum au niveau maximal), `MoonLine.tsx`, `EmpireStatsPage.tsx`, `playerService.ts`
  (`upgradeMoon`), `panels.tsx`.

## Décisions et écarts
- Achat immédiat, sans file ni durée (moins de code serveur, aucun minuteur à surveiller).
- Une lune née avant la 6.14.0 n'a pas de champ `level` : elle est au niveau 1, rien ne change pour elle.
