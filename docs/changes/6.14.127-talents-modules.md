## Migration
- « talents-section-6.14.127 » (section `rules`) : si les règles enregistrées ont `talents.perRank`, la section `talents` est créée
  (si elle n'existe pas) avec les 15 talents livrés à ces valeurs par rang, puis `perRank` quitte les règles. Une section `talents`

- Tant que ces migrations ne sont pas passées, le moteur lit l'ancien réglage en repli (`withDefaultTalents`,

- `appendFromDefaults` des trois sections (I27) : sans effet aujourd'hui (sections neuves) ; le moteur fait aussi revenir un élément
  livré absent à la fusion.
- Aucune donnée de joueur touchée : rangs (`talents.ranks`), plans et modules (`modules.items`) gardent leurs identifiants.

## Décisions et écarts
- **Sections de contenu** (pas `rules.talents.defs` comme les classes en 6.14.125) : demande du lot (« comme unités, technos,
  bâtiments, reliques ») ; garde, historique et chaîne de contenu suivent sans code de plus.
- **Un élément enregistré ne se supprime pas, il se retire** (talents, familles, modèles) : refus du serveur
  (`contentSectionErrors`) et de l'éditeur. Raison : un modèle supprimé effaçait les plans et modules des joueurs à leur prochaine
  sauvegarde (`modulesState`) ; un talent supprimé rendait ses points (perte d'effet sans avertir). « Retiré » garde l'effet de ce qui
  est détenu. Un élément livré absent d'une liste enregistrée revient (comme les classes livrées).
- **« Valeurs par défaut » bloqué** tant qu'un élément ajouté est enregistré (l'effacement de la section n'est pas gardé par le
  serveur) ; un retour arrière du journal vers une version sans un élément ajouté est refusé par la même garde.
- **Valeur par rang** dans chaque effet (un talent peut porter plusieurs effets) ; bornes : part 0,25 par rang (comme 6.14.104),
  niveaux 2, points 5. Famille : part 1, niveaux 20 (comme 6.14.104).
- **Familles** : grandeur libre sauf celles qui demandent une cible (production d'une ressource, capacité d'un hangar) ; une grandeur
  qui vise des unités vise la classe où le module est monté (comme Armement et Blindage) ; sinon effet d'empire.
- **Raretés** (4) restent dans le code (coûts, couleurs, fusion) ; leurs chiffres restent dans `modules` (règles).
- **Branches** (3) restent dans le code (disposition de l'arbre) ; un talent choisit sa branche.
- Le texte de « Réseau d'informateurs » devient « Niveau d'espionnage (+{value} par rang). » (même rendu).
