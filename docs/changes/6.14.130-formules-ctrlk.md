# 6.14.130 : Formules générées depuis les registres et Ctrl+K étendu (AJ27-8)

Type : fonctionnalité (interface, moteur) + tests
Statut : livré (branche de travail `claude/hiver-k-s`, sans PR : Q12)
Source : revue AU27, `docs/audit/2026-10-07-au27-jeu-chaine.md` (AJ-8, AJ-9, lot AJ27-8). Feuille de route
`docs/proposals/feuille-de-route-2030-automne.md`, lot 48.

## Demande
Lot AJ27-8 : « Formules générées depuis les registres (officiers, plafonds, sources) et Ctrl+K étendu (reliques, officiers, boss,
Codex) ». Précisé pour ce lot : sections de Formules générées depuis les registres (officiers, plafonds `effectCaps`, sources
d'effets) au lieu de textes écrits ; Ctrl+K étendu aux reliques, boss (3 types), colonies (biomes, spécialisations), talents, modules,
classes ; manques Ctrl+K retirés de `KNOWN_GAPS`.

Vu par le joueur : la page Formules disait « +1 % d'attaque par niveau » pour l'Amiral même quand l'admin changeait la valeur ;
classe d'empire, modules, lune, mutateur et capsules n'y figuraient pas. « Égide », « Léviathan », « Sable » ne donnaient rien dans
Ctrl+K.

## Diagnostic
- AJ-8 : bloc « Bonus » de `FormulasGuide.tsx` : 5 officiers écrits à la main (seule la valeur était lue), 3 lignes de sources en
  texte libre, un seul plafond cité ; 11 sources dans `EFFECT_SOURCE_LABELS`, 19 grandeurs plafonnées dans `EFFECT_STATS` /
  `effectCaps`.
- AJ-9 : `CommandPalette.tsx` ne cherchait que `UNITS`, `BUILDINGS`, `TECHNOLOGIES` ; la garde de chaîne notait 8 types en manque
  (`*:palette` dans `KNOWN_GAPS`).

## Ce qui change
- Pour le joueur :
  - **Formules → Bonus** : 4 tableaux générés : officiers (effet par niveau et au niveau 20, rares compris), sources d'effets (couche,
    nombre de contenus, grandeurs), plafonds par couche (technologies, empire, alliance ; « − » pour une réduction), classes
    d'empire (effets chiffrés) ; le bloc « Tes bonus actifs » ne change pas ;
  - **Ctrl+K** : reliques, boss mondiaux, d'alliance et de chronique (mois commencé seulement), biomes et spécialisations de colonie,
    talents d'Ascension, modules, classes d'empire et officiers ; 2 lettres au moins, accents ignorés, 3 résultats par type ; un clic
    ouvre la page du contenu (État-major → Reliques / Modules / Commandants, Boss mondial, Alliance → Boss, Boss de saison,
    Colonies, Ascension, Classe d'empire).
- Pour l'admin : rien de nouveau à régler ; un officier, une relique, un talent, un module, une classe, un mutateur ou un plafond
  réglé dans l'admin se voit aussitôt dans Formules et Ctrl+K.
- Dans le code :
  - `src/game/formulasRegistry.ts` (nouveau, moteur pur) : `formulaOfficerRows`, `formulaCapRows`, `formulaSourceRows` (rapport
    d'impact, mutateurs, capsules), `formulaClassRows`, `FORMULA_LAYER_LABELS` ;
  - `src/game/paletteContent.ts` (nouveau, moteur pur) : `paletteContentEntries(nowMs)`, `matchPaletteContent(q, nowMs, max)`,
    `PALETTE_CONTENT_LABELS` ;
  - `FormulasGuide.tsx` (bloc « Bonus »), `CommandPalette.tsx` (entrées de contenu, icône de repli par type) ;
  - `achievements.ts` : `whenLoaded` (au premier chargement du module, un succès dérivé dont le registre n'est pas prêt est
    remis à l'application du contenu ; ensuite, une erreur remonte), `setAchievementList` (registre recalculé une fois par
    application du contenu) ;
  - `contentChain.ts` : `PALETTE_KINDS` = les 11 types ; le maillon « Recherche Ctrl+K » se vérifie contenu par contenu
    (`paletteContentEntries`) hors unités, bâtiments et technos.

## Décisions et écarts
- **La palette mène à la page du système**, pas à la fiche du Codex : le Codex n'a pas de lien direct vers une fiche. Option notée :
  `?fiche=<id>` sur le Codex (AJ27-9, Doctrines et Arsenal).
- **Boss de chronique** : seulement les mois commencés (aucun chapitre à venir dévoilé) ; la garde vérifie tous les mois (date lointaine).
- **Officiers** ajoutés à Ctrl+K (la piste de l'audit les citait), commandants de saison compris.
- **Sections Expéditions et Casino** (citées par AJ-8) : non faites dans ce lot (le lot visait les registres d'effets) ; notées dans
  `constats-ouverts.md`.
- **Capsules** : seule la capsule de blindage passe par le circuit d'effets (défense contre les joueurs) ; la ligne liste les capsules
  du Labo de synthèse et cette grandeur.

### Questions proposées (à reporter dans `QUESTIONS.md`)
1. **Destination d'un résultat Ctrl+K** : page du système (choix fait). Option : fiche du Codex (lien direct à créer). Retour
   arrière : champ `to` de `paletteContentEntries`.
2. **Boss de chronique à venir** : cachés jusqu'au mois (choix fait). Option : tous, pour préparer. Retour arrière : retirer le filtre
   `m.id > month`.
3. **Nombre de résultats par type** : 3 (choix fait, la liste reste lisible à 375 px). Option : 4 comme les unités. Retour arrière :
   argument `max` de `matchPaletteContent`.

Ligne proposée pour CLAUDE.md (règles du front) : « Un nouveau type de contenu se rend trouvable par Ctrl+K en ajoutant ses entrées à
`paletteContentEntries` (`paletteContent.ts`) ; la garde de chaîne le vérifie contenu par contenu. Un tableau de règles des Formules
se lit dans un registre (`formulasRegistry.ts`), jamais en texte écrit. »
