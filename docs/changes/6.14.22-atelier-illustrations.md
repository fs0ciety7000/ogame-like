# 6.14.22 : atelier d'illustrations (dépôt mobile, détourage, WebP)

Type : ajout (outillage), docs
Statut : livré (branche `claude/hiver-k-s`, sans PR : Q12)
Proposition : aucune (demande de l'utilisateur) ; Q28

## Demande
« Je vais générer les images Midjourney. Par contre il faut que je te les envoie et que tu les détoures + conversion en webp. Par contre
je suis sur mobile et je peux pas commit ou push. Comment on peut faire ? Adapte les instructions : pour donner la liste des prompts +
détourage + conversion webp + copy to assets. »

## Diagnostic
Les prompts sont répartis dans cinq fichiers `docs/prompts-*.md`. Rien ne disait quel fichier final attendre (taille, transparence,
emplacement), et l'utilisateur n'a aucun moyen de déposer un fichier depuis son téléphone.

## Ce qui change
- Pour le joueur : sans objet (les images arrivent dans les lots suivants).
- Pour l'utilisateur : page « Atelier d'illustrations » (artifact privé) qui liste les 47 images attendues :
  - 30 technos, la lune, la Cale sèche, 14 objets du Comptoir et l'annonce 5.7 ;
  - pour chacune : prompt à copier, format, détourage ou non, bouton d'envoi, statut (à faire, envoyée, intégrée).
- Dans le code :
  - `scripts/illustrations.json` (source unique) ;
  - `scripts/illustrations.py` (détourage, recadrage, WebP, copie dans `public/assets`, `--missing`, `--page`) ;
  - `scripts/illustrations-page.html` (gabarit) ;
  - procédure dans `docs/illustrations.md`.

## Décisions et écarts
Q28 :
- dépôt par une page Claude (fonctionne sur mobile, sans GitHub ni commit) ;
- détourage seulement pour les objets du Comptoir, affichés en icône comme les reliques (256 × 256, transparents) ;
- les technos, la lune et les bâtiments restent opaques en 512 × 512, comme les images en place ;
- détourage : rembg n'est pas installé, donc retrait du fond sombre par remplissage depuis les bords (les prompts du Comptoir demandent
  un fond sombre et neutre) ;
- la Cale sèche reste en 512 (et non 1 024 comme l'écrivait `prompts-5.28.md`) pour suivre les autres bâtiments.
