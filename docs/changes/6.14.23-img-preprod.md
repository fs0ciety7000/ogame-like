# 6.14.23 : page /img de la pré-prod, envoi des illustrations par lot

Type : ajout (outillage)
Statut : livré (branche `claude/hiver-k-s`, sans PR : Q12)
Proposition : aucune (demande de l'utilisateur) ; Q28

## Demande
« J'aimerais surtout tout envoyer en batch et que tu détectes. […] On peut publier via test.fs0ciety.org/img. À chaque fois qu'une image
est nécessaire, alimente cette page avec les prompts et j'envoie le batch d'images. »

## Diagnostic
La page de 6.14.22 (artifact) demandait un envoi image par image, sur la bonne ligne.

## Ce qui change
- Pour le joueur : sans objet. La page n'apparaît que sur un build qui porte `VITE_SERVER_LABEL` (la pré-prod), et seulement pour un admin
  du jeu ; ailleurs, elle renvoie à `test.fs0ciety.org/img`.
- Pour l'admin :
  - `/img` liste les images à faire (filtres par groupe, « à faire seulement »), avec le prompt à copier, le format et le détourage ;
  - elle prend un lot de fichiers en une sélection et montre les derniers envois, avec leur état (à trier, reconnue, intégrée, écartée).
- Dans le code :
  - `src/pages/IllustrationsPage.tsx` (route `/img`, connexion requise, page à la demande) ;
  - collection `illustration_uploads` (`pb_schema.json`, droits réservés aux admins du jeu, fichiers de 20 Mo au plus en PNG, JPEG ou
    WebP) ;
  - `scripts/preprod-illustrations.mjs` (`pull`, `assign`, `reject`, `integrated`) et `scripts/illustrations-match.mjs`
    (reconnaissance par le nom de fichier).

## Décisions et écarts
Reconnaissance :
- Midjourney nomme ses fichiers d'après le début du prompt. Le script retient une image si au moins 4 mots coïncident, avec 2 d'avance sur
  la candidate suivante ;
- un nom perdu (`IMG_4821`) ou ambigu passe en « à identifier », et Claude compare l'image aux prompts.

La collection existe aussi en production (schéma commun), vide et fermée aux non-admins.

## Invariants et tests
Intégration « 6.14.23 illustrations » : un joueur ordinaire ne peut ni envoyer ni lister ; un admin du jeu envoie et liste. Reconnaissance
essayée sur des noms Midjourney réalistes : 5 sur 5 reconnus ; un nom tronqué et un nom de galerie partent en « à identifier ».
