# 6.14.25 : Seigneurs et Boss du Codex dans « Tout réclamer »

Type : correctif
Statut : livré (branche `claude/hiver-k-s`, sans PR : Q12)
Proposition : aucune (lot H29-3, constat AU29-4, Q27)

## Demande
AU29-4 : depuis la 6.14.17, « Tout réclamer » prenait les catégories du Codex, sauf Seigneurs et Boss (données du serveur).

## Diagnostic
Les seigneurs affrontés (rapports de combat) et les boss du Hall of fame ne sont pas dans la fiche du joueur : le moteur seul ne
pouvait pas voir ces catégories complètes.

## Ce qui change
- Pour le joueur : « Tout réclamer » prend aussi les catégories Seigneurs et Boss complètes. La pastille d'Ordres du jour, calculée par
  le client, ne les compte toujours pas (pas de faux positif) ; la page du Codex les montre.
- Dans le code :
  - `actionNeedsCodex` (`actions.ts`) ;
  - `codexContext` (`cosmic_db.js`, partagé avec la route `codexClaim`), passé à `performPlayerAction` par la route d'action ;
  - `pendingClaims`, `codexClaimableCategories` et `claimCodexCategoryLocal` prennent le contexte en option.

## Décisions et écarts
La pastille reste calculée sans le contexte : la lire coûterait deux requêtes par page. Q27 mise à jour.

## Invariants et tests
`codexBatiments.test.ts` : avec le contexte, la catégorie Seigneurs est proposée et réclamée ; sans lui, elle est refusée.
