Problème joueur : le défenseur perd à budget égal, une cible peut être frappée toutes les heures, le bas du classement reste attaquable,

## Diagnostic
- Noms exacts vérifiés dans le code : `COMBAT_RULES.homeFleetDefenseFactor` et `homeDefenseBonus` (`combat.ts`), `PVP_RULES.shieldAfterDefeatMs`
  et `hardXpRatio` (`pvp.ts`), `STREAK_RULES.chest.common` (`streak.ts`). Groupes de l'admin : Règles → Combat, Protections (`pvp`),
  Série de connexion (et Récompenses).
- **Fusion des règles** : `resolveGameContent` fusionne champ par champ (`chest` compris), donc un serveur **sans** règles enregistrées
  prend les nouveaux défauts. Mais l'admin enregistre la section `rules` **entière** (`saveContentSection`) : un serveur dont l'admin a
  enregistré une règle quelconque garde les anciennes valeurs de tous les champs. D'où la migration `rules-6.14.72` (`CONTENT_MIGRATIONS`,
  `cosmic_db.js`), sur le modèle de `rules-6.2` : un champ qui vaut encore l'ancien défaut prend le nouveau, un champ réglé à la main
  garde sa valeur. La pré-prod (copie de la prod) n'avait pas de règles enregistrées lors de l'audit Z1 : les nouveaux défauts s'y
  appliquent directement.

## Décisions et écarts
- Lune (AE-9) et rattrapage (AE-15), listés en AE-L1 dans le rapport, restent hors de ce lot (consigne du lot : 5 réglages) ; la
  proposition les place en AE-L2 (coût futur, avec l'annonce) et AE-L3 (vérifier I14 d'abord). Choix pris seul, à noter dans
  `QUESTIONS.md`.
- Migration `rules-6.14.72` : remplace seulement une valeur strictement égale à l'ancien défaut (option la plus prudente : un réglage de
  l'admin n'est jamais écrasé). Retour arrière : remettre les anciennes valeurs dans Admin → Règles (la migration ne repasse pas).
- Rien n'est retiré ni rendu : soldes, niveaux et unités restent ; seuls les combats et les coffres à venir changent.
- Le coffre vaut encore 20 h de production du joueur quotidien au moment du coffre (cible 8 à 16 h) : l'indexation sur la production
  (`streak.chest.commonHours` [6, 18], Q99) corrigera l'écart au lot AE-L3.
- Effet de bord attendu : les vaisseaux à quai défendent aussi contre les raids de faction (`pveHomeDefenseFactor`) ; les raids repoussés
  (79 %, cible 60 à 80 %) peuvent monter. À suivre dans la santé de l'équilibre.
