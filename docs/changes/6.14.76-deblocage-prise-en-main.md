## Ce qui change
- Pour le joueur :
  - la carte de l'étape en cours (Prise en main, Carnet) dit ce qu'elle ouvre : « Débloque : Galaxie » (`HudChip` accent), quand la
    page n'était pas déjà ouverte par autre chose ; le bouton « J'y vais » mène toujours à une page ouverte ;
  - Statistiques : panneau Lune seulement avec une lune, une réserve de pitié, ou l'étape « Ta lune » du Carnet atteinte ;
  - Passe (défi en cours) et Chroniques (épisode ouvert, pas fini) : un lien par objectif vers sa page, « Ouvre : Galaxie » si elle
    n'est pas encore au menu ; le clic l'ouvre (marque `nav:<page>`).
- Pour l'admin : sans objet (réglages `navUnlock.pages[…].step`, lot DP-L1).
- Dans le code : `OnboardingChecklist.tsx`, `CommanderGuideCard.tsx` (`useStepOpens`), `EmpireStatsPage.tsx` (`moonPanelVisible`),
  `ObjectiveGoLink.tsx` (nouveau), `SeasonPassPage.tsx`, `ChronicleTimeline.tsx` (prop `goTo`), `ChroniclesPage.tsx` ;
  `changelog/2026-10-07-deblocage-progressif.md` (version 6.14.76, itération 174).
