## Diagnostic
Route logistique à sens unique (colonie → mère) ; un seul lot de défense à la fois sur une colonie.

## Ce qui change
- Joueur :
  - route **Rapatrier** (comme avant) ou **Ravitailler** : la planète mère remplit l'entrepôt de la colonie à 25, 50 ou 80 % à chaque convoi,
    sans descendre sous 30 % de son propre entrepôt ; 10 % perdus en route ; ressources communes seulement ;
  - **file de défense** coloniale : 1 lot en construction + 5 en attente, payés tout de suite ; chaque lot en attente s'annule avec
    remboursement complet.
- Code :
  - `colonies.ts` : `ColonyRoute.direction`, `COLONY_ROUTE_RULES.supplyHomeReservePct`, `colonyRouteLoad` et `runColonyRoute` dans les deux
    sens ; `Colony.defenseQueue`, `COLONY_DEFENSE_QUEUE_MAX`, `colonyDefensePendingSpace`, `startNextColonyDefense` ;
  - `cancel.ts` : cible `colonyDefense` avec `index` (lot en attente) ; `actions.ts` : `direction` sur `colonyRoute` ;
  - `ColoniesPage.tsx` : boutons de sens, remplissage visé, file affichée sous le lot en cours, bouton « Mettre en file ».
- Serveur : rien à changer (actions du moteur, données dans le joueur).

## Décisions et écarts
- Le contrôle de place du hangar compte désormais les lots commandés (en cours et en attente).
- Flotte basée sur une colonie (Q.3) : non livrée.
