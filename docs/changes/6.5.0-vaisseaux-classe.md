## Ce qui change
- Joueur : un vaisseau par classe d'empire, constructible seulement dans cette classe, une fois sa technologie de référence lancée :
  - **Récolteur** (Industriel) : 2 500 / 1 000, attaque 40, défense 60, vitesse 4, soute 160, 2 places ; recycle les débris avec +25 % ;
  - **Croiseur de raid** (Seigneur de guerre) : 6 000 / 3 500, attaque 600, défense 150, vitesse 9, soute 90, 5 places ;
  - **Éclaireur lointain** (Explorateur) : 1 500 / 1 000, attaque 60, défense 40, vitesse 24, soute 30, 1 place ; expédition −15 %.
- Niveau = niveau de la techno de référence (Drone récupérateur, Chasseur, Espionnage), tant que la classe correspond.
- Changer de classe ne retire rien : les vaisseaux restent et volent ; seule la construction est bloquée (message sur la carte).
- Recyclage : la fenêtre propose aussi les Récolteurs quand le joueur en possède.
- Contenu : toujours présents (comme les unités d'élite), verrou de classe réimposé même si la fiche est modifiée ; migration
  `class-units-6.5` (`appendFromDefaults`) pour le contenu personnalisé.
- Code : `classUnits.ts` (nouveau), `units.ts` (`CLASS_UNITS`, `empireClass`, `classTech`), `content.ts`, `actions.ts`, `flush.ts`, `debris.ts`,
  `fleets.ts`, `expeditions.ts`, `balance/analysis.ts` (Récolteur en soutien), `UnitsPage.tsx`, `MissionDialogs.tsx`, `cosmic_db.js`,
  images `public/assets/units/{recolteur,croiseur_raid,eclaireur_lointain}.webp`.

## Décisions et écarts
- Soute du Croiseur de raid : 150 → **90**. À 150, il dominait le Bastion et le Brise-Rempart (invariant « aucune unité dominée ») ;
  à 90 il reste le meilleur pilleur par place (18, Croiseur Nova : 15).
- Les vaisseaux de classe n'utilisent pas `unlockTech` : la techno ne débloque qu'une unité (`UNIT_TO_TECH`), le Drone et le Chasseur
  auraient perdu leur déblocage. D'où `classTech` et une synchronisation à part (`syncClassUnits`).
- Bonus de rôle liés à la flotte, pas à l'empire : ils ne passent pas par le circuit d'effets.

## Invariants et tests
- `classUnits.test.ts` : déblocage par classe et niveau de techno, techno d'origine intacte, changement de classe, recyclage +25 %,
  expédition −15 %. `balance.test.ts` : aucune unité dominée, aucun piège (Récolteur classé en soutien).
