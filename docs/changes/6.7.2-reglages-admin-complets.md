# 6.7.2 : Tous les réglages de GameRules dans le panel admin

Type : ajout (admin) + docs
Statut : livré (branche `claude/hiver-k-s`)
Proposition : aucune (consigne de l'utilisateur)

## Demande
> « Instructions : tout ce qui est dans GameRules etc pour les fonctionnalités existantes et futures doivent pouvoir être gérées dans le panel
> admin ! Ajoute dans tes instructions (.md). »

## Diagnostic
Relevé automatique des 263 champs de `GameRules` : 19 n'avaient aucun champ dans l'admin (XP minimale contre un PNJ, fenêtre de perte d'XP,
date de l'abri en heures, taille de la carte, seuils et fondation des colonies, cadences des routes, contre-espionnage, capacité des débris,
première saison, membres par Quartiers fédérés, rapports partagés, expéditions, podium et Ambre des reliques du Léviathan).

## Ce qui change
- **Admin → Règles → Tous les réglages (avancé)** (`AllRulesEditor.tsx`) : chaque groupe et chaque champ de `GameRules`, affichés selon leur
  type (nombre, oui/non, texte, liste, objet, JSON pour les listes d'objets), avec recherche. Les nouveaux réglages y apparaissent sans code
  d'interface ; les valeurs passent par la validation des règles à l'enregistrement.
- Libellés lisibles pour les 19 champs sans section dédiée.
- Instructions : CLAUDE.md règle n° 2 (citation de la consigne), WORKFLOW.md étape 6 et règle des propositions.

## Invariants et tests
- `rulesAdmin.test.ts` : libellé d'admin pour chaque groupe, valeurs JSON pures (éditables sans perte), éditeur monté dans l'onglet Règles.

## Design (DESIGN.md)
Champs d'admin existants (`NumberField`, `CheckboxField`, `TextField`, `TextAreaField`), carte repliable. Vérifié à 375 px et 1 400 px.
