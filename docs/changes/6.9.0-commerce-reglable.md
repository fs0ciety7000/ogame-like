# 6.9.0 : Commerce réglable dans l'admin (AU4)

Type : correctif (règle n° 2) + ajout (admin)
Statut : livré (branche `claude/hiver-k-s`)
Proposition : aucune (correctif de la revue AU4, `docs/audit/2026-10-06-au4-commerce.md`, COM-1)

## Demande
Revue AU4 de la feuille de route (enchaînée automatiquement, règle n° 3) ; règle n° 2 : « tout ce qui est dans GameRules etc. […] doit pouvoir
être géré dans le panel admin ».

## Diagnostic
COM-1 : enchères, contrats de livraison, cadeaux, concours, points du tournoi du casino, offre de la semaine du Comptoir et classement des
mécènes avaient leurs chiffres en dur dans le code.

## Ce qui change
- **Joueur** : rien (mêmes valeurs par défaut).
- **Admin** : Admin → Règles, trois sections : « Enchères », « Contrats de livraison et cadeaux », « Pot commun : concours, tournoi,
  Comptoir » ; aussi dans « Tous les réglages (avancé) ».
- **Code** : 7 groupes de `GameRules` (`auctions`, `tradeContracts`, `gifts`, `contests`, `tournamentPoints`, `weeklyStock`, `patrons`) ;
  `AUCTION_RULES.watchMax/historyPerLot/historyMaxLots` (alertes et historique lus par accesseurs), `TRADE_CONTRACT_RULES.priorityHours`
  (remplace `PRIORITY_CONTRACT_HOURS`), `WEEKLY_STOCK_RULES` (prix et exemplaires lus par accesseurs dans `WEEKLY_OFFERS`), `PATRON_RULES`
  (remplace `PATRONS_TOP`) ; validation dans `validateRules` ; `CommerceRulesFields.tsx`.

## Décisions et écarts
Les offres de la semaine gardent leur liste fixe (identifiants liés au tirage des récompenses) : seuls prix et exemplaires sont réglables.

validation.
