## 5. Déroulé proposé

1. **Choisir un créneau calme** (matin en semaine) ; annoncer une courte maintenance si voulu (Admin → Maintenance).
2. **Ouvrir la PR** `claude/hiver-k-s` → `main` (Claude peut la rédiger sur demande : titre, fiches portées, ce dossier).
3. **CI verte** (lint, tests, build, intégration PocketBase) puis fusion.
4. Le workflow **Déploiement serveur** (`.github/workflows/deploy.yml`) fait seul : **sauvegarde complète**, schéma, fiches
   publiques, hooks au commit fusionné. Vercel déploie le front.
5. **Vérifications** (Claude peut les lancer en lecture seule) :
   - `GET /api/cosmic/version` → `6.14.17` (version du dernier changelog joueur) ;
   - `GET /api/cosmic/status` → services ok, pas de maintenance ;
   - `content_migrations` : les 8 migrations ci-dessus ;
   - Admin → Équilibrage → Santé : nouvelles tuiles (raids, élites, casino, pot) ;
   - nombre de joueurs inchangé, une connexion et une action de jeu réussies.
6. **Annoncer** : billet de devblog récapitulatif (à écrire, lot suivant possible) et annonce en jeu.
