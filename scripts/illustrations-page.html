  1. « Copier le prompt », colle-le dans Midjourney.
  2. Choisis la variante, fais « Upscale », enregistre l'image dans ta galerie.
  3. Ici, « Envoyer l'image » sur la ligne de cette image (PNG, JPEG ou WebP).
  4. Dis « images envoyées » dans la session Claude : la ligne passe à « Intégrée » quand le fichier est dans le jeu.
L'envoi d'images demande la page ouverte dans claude.ai, connecté avec ton compte. Les prompts restent copiables.
Formats : technologies, lune et bâtiments en 512 × 512 opaques ; objets du Comptoir en 256 × 256 détourés (fond transparent) ; annonce en 1 920 px de large. Pas de texte dans les images.
